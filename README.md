## Selam Forcastung Financial Inclusion in Ethiopia

This project builds a forecasting system to track Ethiopia’s digital financial transformation using time series analysis, event impact modeling, and scenario-based forecasting. The system focuses on the two core Global Findex dimensions of financial inclusion: Access (account ownership) and Usage (digital payments).
